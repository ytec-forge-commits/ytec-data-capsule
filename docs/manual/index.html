1. 使用前の確認

  • 技術的な対応対象はWindows 7 SP1 / 8 / 8.1 / 10 / 11、.NET Framework 4.6.1以降です。AnyCPU版は32ビット・64ビットWindowsに対応しますが、Windows 11には32ビット版OSはありません。
  • ZIPをフォルダーへ展開し、Y-TEC Data Capsule.exeをダブルクリックします。EXEだけを別の場所へ移動しないでください。
  • アプリは管理者権限を自動要求します。ユーザーアカウント制御が表示されたら、入手元を確認して許可します。毎回右クリックして「管理者として実行」を選ぶ必要はありません。
  • 1.2.0再公開版のEXEと同梱DLLはY-TECの自己署名方式です。Microsoftや商用CAが信頼する署名ではなく、WindowsやSmartScreenの警告が表示される場合があります。公式配布元と公開されたSHA-256を確認してください。公開鍵証明書を自動登録する処理はありません。
  • 外部通信、クラウド同期、アクセス解析は行いません。OneDrive / iCloud等のオンライン専用ファイルも自動ダウンロードしません。

古いWindowsや.NET Framework 4.6.1の技術的対応は、Microsoftによる現在の保守を意味しません。旧OSの互換性は過去の試験記録であり、今回の再公開で全OSを再試験したものではありません。

バックアップ完了だけで元PCを消さないでください。移行先PCで必要なファイルを開き、Thunderbird・年賀状・会計・Appleデバイス等は対象ソフトから認識できることまで確認してください。

2. 起動時の3モード

1 データバックアップ
文書・写真・ブックマーク・メール・年賀状・会計・MobileSync・Wi-Fi設定などを保存します。
2 Wi-Fi設定の復元
Data Capsuleで暗号化保存したWi-Fi設定を別PCへ登録します。
3 ブックマークの復元
Chrome・Edge・Firefoxのブックマークだけを戻します。

3. データをバックアップする

1
元のWindowsドライブを選ぶ
直下にWindowsフォルダーがある内蔵・USBドライブだけが表示されます。USBドライブを後から接続した場合は［再検出］を押します。
2
保存場所を選ぶ
外付けSSDなど、新しいバックアップフォルダーを作る親フォルダーを選びます。元のWindowsドライブ内は選べません。
3
新規フォルダー名を入力する
例: 20260728丸ごとバックアップ。同名のファイルやフォルダーがある場合は、別名へ変更します。
4
項目を選ぶ
［すべてチェック］［すべて外す］、グループごとのチェック、個別項目の3段階で選べます。グループ名左の矢印で個別項目を開きます。
5
内容を確認する
ファイル数・予定容量・警告・作成先を確認します。オンライン専用ファイルが見つかった場合は、対象外の件数と表示サイズも確認します。設定を変えた場合は、もう一度確認します。
6
開始する
確認画面を読み、開始します。現在のWindowsドライブからブラウザーブックマークを保存する場合は、対象ブラウザーを自動終了します。未保存の入力内容は先に保存してください。
完了後は［作成したフォルダーを開く］から結果を確認できます。backup-manifest.v1.jsonにはコピー件数、失敗、警告、ACL結果が記録されます。コピー中は保存先ドライブを抜かないでください。

4. バックアップ項目と出力先

バックアップルートの下にdata、Wi-Fi設定はwindows-settingsが作成されます。一般ファイルは元ドライブからの相対位置を残すため、どのユーザーのデータかを判別できます。

グループ主な内容と注意
基本データデスクトップ、ドキュメント、ダウンロード、ピクチャ、ミュージック、ビデオ。OneDrive / iCloud等はPC内に完全な実体があるファイルだけをコピーします。
ブラウザーIE / Chrome / Edge / Firefoxのブックマークのみ。パスワード、Cookie、履歴、セッションは保存しません。
メールThunderbird、Outlookデータ、Windows Mail系。使用中ファイルはVSSを試み、取得できなければ警告します。
端末データiPhone / iPadのMobileSync。AppData内とユーザーフォルダー直下を両方探索します。
Windows設定Data Capsuleを実行しているPCのWi-Fi設定を、別PCへ移せる暗号化ファイルとして保存します。
年賀状ソフト個人ユーザーとPublic / All Usersの住所録候補を別々の項目で探索し、個人分と共有分を混ぜずにソフト別フォルダーへ整理します。対応製品は「8. 年賀状ソフト」を参照してください。
会計ソフト弥生会計・やよいの青色申告、フリーウェイ経理の候補。公式バックアップを必ず優先します。

出力例

  • D:\20260728丸ごとバックアップ\data\Users\旧ユーザー名\Documents
  • D:\20260728丸ごとバックアップ\data\年賀状ソフト\筆王
  • D:\20260728丸ごとバックアップ\data\年賀状ソフト\共有住所録\筆ぐるめ
  • D:\20260728丸ごとバックアップ\data\会計ソフト\弥生会計・やよいの青色申告
  • D:\20260728丸ごとバックアップ\windows-settings\wifi

5. 手動移行・復元の共通手順

Wi-Fi設定とブラウザーブックマーク以外は、Data Capsuleが移行先アプリへ自動投入しません。次の順番で安全に戻します。

  1. バックアップルートを保管する: backup-manifest.v1.jsonがある一番上のフォルダーを、作業が終わるまで変更・削除しません。
  2. 移行先アプリを先に入れる: 可能なら移行元と同じ版、またはメーカーが案内する互換版をインストールし、一度起動して保存先を作ります。
  3. 移行先アプリを終了する: コピー対象を使用中のまま上書きしません。タスクトレイに残るアプリも終了します。
  4. 移行先の現データを退避する: 既存フォルダーを別名にするか別の場所へコピーし、戻せる状態にします。
  5. 必要なデータだけをコピーまたは取り込む: バックアップのdata\Users\旧ユーザー名から、移行先の現在のユーザーフォルダーへコピーします。「移動」ではなく「コピー」を使います。
  6. 対象ソフトで確認する: ファイルを開き、件数・更新日・年度・アカウント等を確認します。確認できるまで旧PCやバックアップを消しません。
AppData全体をまとめて上書きしないでください。Windowsやアプリの版、ユーザー名が異なると起動不能や設定破損の原因になります。Thunderbird、MobileSync、年賀状、会計は次節以降の手順を使ってください。

基本データの戻し先

バックアップ内通常の戻し先
data\Users\旧ユーザー名\Desktop現在のユーザーのデスクトップ
...\Documents現在のユーザーのドキュメント
...\Pictures現在のユーザーのピクチャ
...\Downloads現在のユーザーのダウンロード。実行ファイルは入手元を再確認してから開きます。
OneDrive / iCloud等のクラウド同期フォルダー: PC内に完全な実体があるファイルだけをコピーします。オンライン専用または一部未取得のファイルは開かずに除外するため、バックアップ中に大容量の自動ダウンロードは行いません。除外件数は確認画面、完了画面、backup-manifest.v1.jsonで確認できます。必要なファイルだけ事前にダウンロードして再実行するか、移行先で同じクラウドサービスから同期してください。

6. Thunderbird

バックアップできる範囲

保存するもの保存しないもの
メール本体、POPやローカルフォルダー、IMAPのローカルデータ、アカウント設定、アドレス帳、フィルター、カレンダー・アドオン等のプロファイル内データ。 既知の保存パスワードDB、鍵DB、Cookie、セッション・クラッシュ復旧用ファイル。具体的にはlogins.json、key3.db、key4.db、signons*、cookies.sqlite*、主なsession/recoveryファイルです。
パスワードを除外するため、復元後は各メールアカウントのパスワードを再入力します。IMAPはサーバーから再同期できますが、POP受信済みメールと「ローカルフォルダー」はバックアップが特に重要です。

推奨: Thunderbirdのインポートツールで戻す

  1. 移行先へThunderbirdをインストールします。可能なら移行元と同じ版か、より新しい安定版にします。
  2. バックアップ内のdata\Users\旧ユーザー名\AppData\Roaming\Thunderbird\Profiles\プロファイル名を探します。Windows XP系ではApplication Data\Thunderbird\Profilesです。
  3. Thunderbirdのメニュー［≡］→［ツール］→［設定とデータのインポート］を開きます。
  4. ［別にインストールしたThunderbirdからインポート］を選び、［プロファイルフォルダーを選択］から手順2のプロファイルを指定します。
  5. アカウント設定、メッセージ、アドレス帳など必要な項目を選び、開始します。
  6. 再起動後、メール件数・ローカルフォルダー・アドレス帳を確認し、求められたパスワードを再入力します。

Mozillaの案内では、ZIPからのインポートは2GBまでです。Data CapsuleはZIP化したThunderbirdプロファイルではないため、容量が大きい場合も上記の「プロファイルフォルダーを選択」を使用します。

代替: Thunderbirdフォルダーを丸ごと置き換える

  1. 移行先でThunderbirdを一度起動し、すぐ終了します。
  2. %APPDATA%を開き、現在のThunderbirdフォルダーをThunderbird.before-restore等へ改名して退避します。
  3. バックアップ内のAppData\Roaming\Thunderbirdフォルダーを、移行先の%APPDATA%へコピーします。
  4. Thunderbirdを起動して確認します。起動できない場合は退避したフォルダーへ戻し、インポートツールを使用します。
Mozilla公式案内: 設定とデータをThunderbirdにインポートする / Thunderbirdのデータを新しいコンピューターに移動する（リンクを開くにはインターネット接続が必要です）。

7. iPhone / iPad（MobileSync）

保存する場所

  • デスクトップ版iTunes系: data\Users\旧ユーザー名\AppData\Roaming\Apple Computer\MobileSync
  • Microsoft Store版iTunes / Appleデバイス系: data\Users\旧ユーザー名\Apple\MobileSync

両方が見つかれば両方を保存します。実際の端末バックアップは各MobileSync\Backup配下にある長い英数字名のフォルダーです。フォルダー名や内部ファイルを変更しないでください。

移行先で認識させて復元する

  1. 移行先へAppleデバイスアプリ、または利用するiTunesをインストールし、最新版へ更新します。
  2. アプリを一度起動します。Appleデバイスアプリなら［一般］→［バックアップを管理］→［エクスプローラーに表示］で、移行先が実際に使用するBackupフォルダーを確認できます。
  3. Appleデバイスアプリ / iTunesを完全に終了します。
  4. 手順2で確認したMobileSync\Backupへ、バックアップ内のMobileSync\Backupにある端末別フォルダーをコピーします。すでに同名フォルダーがある場合は上書きせず、移行先側を先に別の場所へ退避します。
  5. アプリを開き、［バックアップを管理］またはiTunesの［編集］→［環境設定］→［デバイス］で、日付と端末名を確認します。
  6. iPhone / iPadを接続し、端末側で「このコンピュータを信頼」を許可します。
  7. Appleデバイスアプリの［一般］、またはiTunesの［概要］から［バックアップを復元］を選び、目的のバックアップを指定します。
暗号化済みローカルバックアップには、作成時のパスワードが必要です。Data Capsuleはそのパスワードを保存・解除しません。パスワードが分からない暗号化バックアップは復元できません。

バックアップが一覧へ出ない場合は、コピー先方式が合っているか、Backupが二重（Backup\Backup）になっていないか、端末別フォルダーの中身を変更していないか確認します。

Apple公式案内: バックアップを探して管理する / Windowsでバックアップ・復元する（リンクを開くにはインターネット接続が必要です）。

8. 年賀状ソフト

Data Capsuleは次の製品の住所録候補を、個人住所録と共有住所録に分けて分類します。バックアップ画面で「年賀状ソフト」グループをまとめてチェックすると、個人用と共有用の両項目を選択できます。

画面の項目探索する場所保存先
年賀状ソフト・住所録データ各ユーザーのDocuments / My Documents / Desktopdata\年賀状ソフト\製品名
年賀状ソフト・共有住所録データUsers\Public\Documents、Users\Public\Desktop、旧WindowsのAll Users相当data\年賀状ソフト\共有住所録\製品名
たとえば筆ぐるめのPublic\Documents\みんなの筆ぐるめにある.FGA住所録は、data\年賀状ソフト\共有住所録\筆ぐるめへ保存します。個人ユーザーの住所録とは混ざりません。

対応製品と主な対象

筆ぐるめ.FGA
筆まめ.FWA / .FWB / .SDL
楽々はがき.JSR
宛名職人.ATA

移行・復元の手順

  1. 移行先に同じ製品の対応版をインストールします。
  2. 製品を起動し、［住所録を開く］［他形式から取り込む］［バックアップから復元］等、メーカーが案内する操作を選びます。
  3. 個人用はdata\年賀状ソフト\製品名、共有用はdata\年賀状ソフト\共有住所録\製品名から対象ファイルを指定します。
  4. 氏名・郵便番号・住所・件数を確認します。印刷前に必ずプレビューします。
製品や版によって住所録形式が変わることがあります。Data Capsuleは住所録候補のコピーと分類までを行い、製品内への自動復元は行いません。メーカーの公式移行手順がある場合は、そちらを優先してください。

9. 会計ソフト

会計データ機能は実装済みで、合成データによる検出・分類・コピーは確認済みですが、実会計ソフトでの読込受入はリリース判断により省略しています。Data Capsuleだけを唯一のバックアップ手段にしないでください。

現在の自動対象

  • 弥生会計 / やよいの青色申告: Documents内の事業所データ候補
  • フリーウェイ経理: 選択したWindowsドライブ直下のKAIKEI_K

移行・復元の手順

  1. 移行元で会計ソフトを起動し、メーカーまたは販売店の公式手順でバックアップデータを作成します。
  2. Data Capsuleの会計項目は、公式バックアップに追加する補助コピーとして実行します。
  3. 移行先へ対象会計ソフトの対応版をインストールします。
  4. 会計ソフト内の［バックアップの復元］［事業所データを開く］等を使い、まず公式バックアップから復元します。
  5. Data Capsuleのコピーを使う必要がある場合は、data\会計ソフト\製品名からメーカー指定の場所へコピーし、製品の「開く」操作で指定します。
  6. 事業所名、会計年度、期首・期末、残高、仕訳件数を照合します。

PCA会計、ブルーリターンAなど、ソフト内で専用バックアップ作成が必要な製品は自動対象外です。各製品の公式バックアップ・復元手順だけを使用してください。

10. Wi-Fi設定を復元する

  1. 起動画面で［Wi-Fi設定の復元］を選びます。
  2. ［一番上のフォルダーを選択］を押し、例 D:\20260728丸ごとバックアップのようなバックアップルートを選びます。
  3. 内部のwindows-settings\wifi\wifi-profiles.ywbwifiは自動検出されます。
  4. 警告を確認し、［Wi-Fi設定を復元］を押します。
  5. WindowsのWi-Fi一覧から目的のSSIDへ接続できることを確認します。
同名SSIDの設定がある場合は更新される可能性があります。SSIDとパスワードは画面・ログへ表示しません。暗号化は平文露出防止を目的としたアプリ内蔵鍵方式で、EXEを詳しく解析できる相手への耐性は限定的です。

11. ブックマークを復元する

  1. 起動画面で［ブラウザーブックマークの復元］を選びます。
  2. バックアップの一番上のフォルダーを選びます。内部の対象ファイルは自動検出されます。
  3. 復元したいバックアップ元ユーザー・ブラウザープロファイルを選びます。
  4. 未保存のフォーム入力等を保存して開始します。対象ブラウザーへ通常終了を依頼し、残るバックグラウンドプロセスは強制終了します。
  5. Chrome / Edgeは復元先を確認します。現在のBookmarksとBookmarks.bakを退避してから置き換えます。
  6. Firefoxはファイル検証後に場所が開きます。Firefoxの［ブックマークを管理］→［インポートとバックアップ］→［復元］→［ファイルを選択］で指定します。
  7. ブラウザーを起動し、ブックマークバーとフォルダー構成を確認します。
復元するのはブックマークだけです。パスワード、Cookie、履歴、セッションには触れません。ブラウザープロセスの実行ファイルを安全に特定できない場合は処理を開始せず、手動終了を案内します。

13. 困ったとき

症状確認すること
元ドライブが表示されないドライブ直下にWindowsフォルダーがあるか、USBが認識されているか確認し、［再検出］を押します。
開始できない管理者権限、新規フォルダー名、同名の有無、空き容量、保存先形式、内容確認の再実行を確認します。
Wi-Fi / ブックマークが見つからない内部フォルダーではなく、backup-manifest.v1.jsonがある一番上のフォルダーを選びます。
ブラウザーを終了できない未保存内容を保存し、対象ブラウザーとバックグラウンド常駐を手動終了して再実行します。
Thunderbirdに入らない実際のProfiles\プロファイル名を選んだか、移行元と同じ版または新しい版か確認します。丸ごと置換前の退避へ戻せます。
MobileSyncが一覧に出ないAppleアプリの［バックアップを管理］から実際の保存先を開き、Backup\Backupの二重構造やフォルダー名変更がないか確認します。
OneDrive / iCloudの件数が少ないオンライン専用ファイルは自動ダウンロードせず対象外にします。必要なファイルだけPCへダウンロードして新しいバックアップフォルダー名で再実行するか、移行先で同じクラウドサービスから同期します。
一部ファイルが失敗したbackup-manifest.v1.jsonの警告を確認し、対象アプリを終了して新しいフォルダー名で再実行します。
マニュアルが開かないEXEだけを移動せず、ZIPを展開し直してください。PDF版は操作マニュアルフォルダーにあります。

1. Before you begin

  • Technical targets are Windows 7 SP1, 8, 8.1, 10, and 11 with .NET Framework 4.6.1 or later. The AnyCPU build supports 32-bit and 64-bit Windows; Windows 11 has no 32-bit OS edition.
  • Extract the ZIP to a folder and double-click Y-TEC Data Capsule.exe. Keep the EXE with its DLLs, catalog, and manual folders.
  • The app requests administrator privileges automatically. Check the source, then approve the Windows UAC prompt. You do not need to right-click “Run as administrator” every time.
  • The republished 1.2.0 EXE and bundled DLLs use Y-TEC self-signing. This is not a signature trusted by Microsoft or a commercial CA, and Windows or SmartScreen may display warnings. Check the official download source and published SHA-256 values. No public certificate is installed automatically.
  • The app performs no network communication, cloud synchronization, or analytics. It does not download online-only OneDrive or iCloud content.

Technical compatibility with older Windows and .NET Framework 4.6.1 does not imply current Microsoft servicing. Older OS compatibility refers to historical tests, not a new test of every OS for this republication.

Do not erase the old PC just because the backup completed. Open required files on the destination PC and confirm that Thunderbird, postcard, accounting, and Apple applications recognize their data first.

Save documents, photos, bookmarks, mail, address books, accounting data, MobileSync, Wi-Fi profiles, and more.

3 Restore Browser Bookmarks
Restore only Chrome, Edge, or Firefox bookmarks.

3. Create a data backup

1
Select the source Windows drive.
Only internal or USB drives with a root-level Windows folder appear. Select “Scan Again” after connecting a USB drive.
2
Select the destination location.
Choose the parent folder where a new backup folder will be created, such as an external SSD. A location inside the source Windows drive is not allowed.
3
Enter a new folder name.
For example, 20260728-Full-Backup. If the same file or folder name already exists, choose another name.
4
Select backup items.
Use Select All, Clear All, a group checkbox, or individual item checkboxes. Expand the arrow beside a group to show its items.
5
Review the contents.
Check the file count, planned size, warnings, and final output path. If cloud placeholders were found, review the skipped count and displayed logical size. Review again after changing any setting.
6
Start the backup.
Read the confirmation first. When backing up current browser bookmarks, the target browsers close automatically. Save unfinished form input before continuing.
After completion, select “Open Created Folder” and review backup-manifest.v1.json for copied files, failures, warnings, and ACL results. Never disconnect the destination while copying.

4. Backup items and output

Ordinary files are placed under data; Wi-Fi settings are placed under windows-settings. Source-relative paths are preserved so each source user remains identifiable.

5. General manual migration and restore

Except for Wi-Fi profiles and browser bookmarks, Data Capsule does not inject data into destination applications. Use this order:

  1. Preserve the backup root: Keep the top-level folder containing backup-manifest.v1.json unchanged until the migration is fully validated.
  2. Install the destination application first: Prefer the same version as the source, or a compatible version documented by the vendor. Launch it once so it creates its folders.
  3. Exit the application: Never replace files while the application or its tray process is using them.
  4. Protect destination data: Rename or copy the current destination folder so that you can roll back.
  5. Copy or import only what is needed: Copy from data\Users\OldUser into the current user's destination. Use Copy, not Move.
  6. Validate in the application: Check files, counts, dates, years, and accounts. Do not erase the old PC or backup until validation succeeds.
Do not overwrite all of AppData. Different Windows versions, application versions, and user names can prevent startup or corrupt settings. Use the dedicated Thunderbird, MobileSync, postcard, and accounting instructions below.

Common destinations for basic data

Path inside the backupUsual destination
data\Users\OldUser\DesktopThe current user's Desktop
...\DocumentsThe current user's Documents
...\PicturesThe current user's Pictures
...\DownloadsThe current user's Downloads. Recheck the source of executable files before opening them.
OneDrive, iCloud, and similar folders: Only fully local files are copied. Online-only and partially retrieved files are skipped without being opened, so the app will not trigger a large download. Review skipped counts in the plan, completion dialog, and manifest. Download only required source files and run a new backup, or sync them again from the same cloud service on the destination.

6. Thunderbird

What is and is not backed up

IncludedExcluded
Message stores, POP and Local Folders, local IMAP data, account settings, address books, filters, calendars, add-ons, and other profile data. Known saved-password databases, key databases, cookies, and session or crash-recovery files, including logins.json, key3.db, key4.db, signons*, cookies.sqlite*, and common session/recovery files.
Re-enter each mail-account password after restore. IMAP data can normally resynchronize from its server, but downloaded POP mail and Local Folders depend especially on the backup.

Recommended: use Thunderbird's import tool

  1. Install Thunderbird on the destination PC, preferably the same or a newer stable version.
  2. Locate data\Users\OldUser\AppData\Roaming\Thunderbird\Profiles\ProfileName. Older Windows layouts may use Application Data\Thunderbird\Profiles.
  3. In Thunderbird, open Menu (≡) > Tools > Import.
  4. Choose Import from another Thunderbird installation, then choose the profile folder found in step 2.
  5. Select the account settings, messages, address books, and other required items, then start the import.
  6. After restart, check message counts, Local Folders, and address books, and re-enter requested passwords.

Mozilla documents a 2 GB limit for importing a ZIP. Data Capsule does not create a Thunderbird ZIP, so choose the profile folder directly for large profiles.

Alternative: replace the Thunderbird folder

  1. Launch Thunderbird once on the destination PC, then exit it completely.
  2. Open %APPDATA% and rename the current Thunderbird folder to a rollback name such as Thunderbird.before-restore.
  3. Copy the backed-up AppData\Roaming\Thunderbird folder into the destination %APPDATA%.
  4. Start Thunderbird and validate it. If it fails, restore the renamed folder and use the import tool instead.
Mozilla guidance: Import settings and data into Thunderbird / Move Thunderbird data to a new computer (Internet access is required to open these links).

7. iPhone / iPad (MobileSync)

Locations saved by Data Capsule

  • Desktop iTunes: data\Users\OldUser\AppData\Roaming\Apple Computer\MobileSync
  • Microsoft Store iTunes / Apple Devices: data\Users\OldUser\Apple\MobileSync

Both are saved when both exist. The actual device backups are long alphanumeric folders under each MobileSync\Backup. Do not rename these folders or edit their contents.

Make the destination recognize and restore the backup

  1. Install and update Apple Devices or the intended version of iTunes on the destination PC.
  2. Launch it once. In Apple Devices, use General > Manage Backups > Show in Explorer to identify the actual destination Backup folder.
  3. Exit Apple Devices or iTunes completely.
  4. Copy the per-device folders from the backed-up MobileSync\Backup into the destination MobileSync\Backup. If a name already exists, back up the destination copy first; do not merge blindly.
  5. Open the app and confirm the device and date under Manage Backups, or in iTunes under Edit > Preferences > Devices.
  6. Connect the iPhone or iPad and approve “Trust This Computer” on the device.
  7. Choose Restore Backup under General in Apple Devices, or under Summary in iTunes, and select the intended backup.
An encrypted local Apple backup requires the password used when it was created. Data Capsule does not save, recover, or bypass that password. An encrypted backup cannot be restored without it.

If the backup is missing from the list, check the destination layout, make sure it is not nested as Backup\Backup, and confirm that the per-device folder name and contents were not changed.

Apple guidance: Locate and manage backups / Back up and restore with Apple Devices on Windows (Internet access is required to open these links).

Migration and restore

  1. Install a compatible edition of the same product on the destination PC.
  2. Use the vendor's Open Address Book, Import Another Format, or Restore Backup command.
  3. Choose personal files under data\年賀状ソフト\ProductName or shared files under data\年賀状ソフト\共有住所録\ProductName.
  4. Validate names, postal codes, addresses, and record counts. Always preview before printing.
Address-book formats can vary by product and version. Data Capsule copies and classifies candidates but does not restore them inside the product. Follow official vendor migration instructions when available.

9. Accounting software

Accounting-data detection, classification, and copying are implemented and verified with synthetic data, but import acceptance with the commercial accounting applications was omitted from this release decision. Never use Data Capsule as the only accounting backup.

Current automatic targets

  • Yayoi Accounting / Yayoi Blue Return: candidate business data under Documents
  • FreeWay Accounting: KAIKEI_K at the root of the selected Windows drive

Migration and restore

  1. On the source PC, use the accounting product's official procedure to create a backup.
  2. Use Data Capsule's accounting item only as an additional copy beside that official backup.
  3. Install a compatible edition of the accounting product on the destination PC.
  4. Restore the official backup first through the product's Restore Backup or Open Business Data command.
  5. If the Data Capsule copy is needed, copy from data\会計ソフト\ProductName to the vendor-specified location and select it through the product's Open command.
  6. Compare the business name, fiscal year, opening and closing periods, balances, and journal-entry count.

Products such as PCA Accounting and Blue Return A that require a dedicated in-product backup are intentionally not automatic targets. Use only their official backup and restore procedures.

10. Restore Wi-Fi profiles

  1. Select Restore Wi-Fi Profiles on the startup screen.
  2. Select the top-level backup folder, for example E:\20260728-Full-Backup.
  3. The app locates windows-settings\wifi\wifi-profiles.ywbwifi automatically.
  4. Review the warning, then select Restore Wi-Fi Profiles.
  5. Confirm that Windows can connect to the intended network.
An existing Windows profile with the same SSID may be updated. SSIDs and passwords are never displayed or logged. The embedded-key encryption prevents casual plaintext exposure but has limited resistance to detailed executable analysis.

11. Restore browser bookmarks

  1. Select Restore Browser Bookmarks on the startup screen.
  2. Select the top-level backup folder. The app locates supported bookmark files automatically.
  3. Select the source backup user and browser profile.
  4. Save unfinished form input before starting. The target browser is asked to exit; remaining background processes are terminated.
  5. For Chrome or Edge, confirm the destination profile. The current Bookmarks and Bookmarks.bak are saved to a rollback folder before replacement.
  6. For Firefox, the app validates and locates the backup. In Firefox use Manage Bookmarks > Import and Backup > Restore > Choose File.
  7. Start the browser and confirm the bookmark bar and folder structure.
Only bookmarks are restored. Passwords, cookies, history, and sessions are untouched. If the browser executable cannot be identified safely, the app does not start the restore and asks you to close it manually.

12. Storage formats, access control, and rights

DestinationBehavior
NTFS / ReFSAfter completion, only the new backup output from the current run receives owner Everyone and inheritable full control. Source owners and ACLs are unchanged.
exFATBackup is allowed. exFAT cannot store Windows owners or ACLs, so Everyone ACL processing is skipped.
FAT32Rejected before copying because of restrictions such as the 4 GB single-file limit.
Everyone full control and exFAT make backup content easy to read or modify for anyone who can connect the drive. Protect personal backups physically, consider BitLocker or other drive encryption, and securely erase them when no longer required.

13. Troubleshooting

SymptomWhat to check
The source drive does not appearConfirm a root-level Windows folder and a recognized USB connection, then select Scan Again.
Backup cannot startCheck administrator privileges, the new folder name, existing names, free space, destination format, and whether the plan was reviewed again.
Wi-Fi or bookmarks are not foundSelect the top-level folder containing backup-manifest.v1.json, not an internal data folder.
A browser cannot closeSave unfinished work, close the browser and its background tray process manually, then retry.
Thunderbird import failsSelect the actual Profiles\ProfileName, use the same or a newer Thunderbird version, or restore the rollback made before folder replacement.
MobileSync is missingUse Manage Backups to open the real destination and check for accidental Backup\Backup nesting or changed folder names.
OneDrive / iCloud file count is lowOnline-only files are intentionally skipped. Download only required source files and create a new backup, or sync them on the destination PC.
Some files failedReview warnings in backup-manifest.v1.json, exit the relevant app, and retry with a new backup folder name.
The manual does not openExtract the ZIP again and keep the EXE with its folders. The PDF is in the User Manual folder.

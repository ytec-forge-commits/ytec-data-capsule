Y-TEC Data Capsule 1.2.0
ポータブル正式版（2026-09-29再公開・Y-TEC自己署名）

■ 起動

1. ZIPをフォルダーへ展開します。
2. Y-TEC Data Capsule.exe を起動します。
3. Windowsのユーザーアカウント制御が表示されたら、ファイルの入手元を
   確認してから許可します。

EXEだけを別の場所へ移動せず、DLL、configフォルダー、操作マニュアルを
同じフォルダーに置いたまま使用してください。インストール、外部通信、
クラウド同期は行いません。

■ 動作環境

- Windows 7 SP1 / 8 / 8.1 / 10 / 11
- 32ビットWindows / 64ビットWindows（AnyCPUで自動判定）
- .NET Framework 4.6.1以降

■ 安全上の重要事項

- 元データを削除、移動、改名、上書きしません。
- 元ドライブは、直下にWindowsフォルダーがある内蔵・USBドライブだけを
  ドロップダウンへ自動表示します。接続後は「再検出」を押してください。
- 保存場所を選び、任意の名前を入力して、実行ごとに新しい
  バックアップフォルダーを作ります。同名がある場合は開始しません。
- バックアップ項目は、全項目・グループ・個別項目で選択できます。
- NTFS / ReFSでは、今回の出力物だけをEveryone所有者・フルアクセスへ
  変更します。exFATはACLを保存できないためACL処理を行いません。
  FAT32は実行前に拒否します。
- IE / Edge / Chrome / Firefoxはブックマークだけを対象とします。
  パスワード、Cookie、履歴、セッションは保存しません。
- ブックマークのバックアップ・復元前に対象ブラウザーを自動終了します。
  未保存の入力内容を保存してから実行してください。
- Wi-Fi設定は別PCへ移行できる暗号化ファイルとして保存します。
  アプリ内蔵鍵のため平文露出は防ぎますが、解析耐性は限定的です。
- 通常コピーできない使用中ファイルは、利用可能な場合だけVSSから
  再取得します。取得できないファイルは警告とマニフェストへ記録します。

■ バックアップ後の移行・復元

操作マニュアルには、次の手順を掲載しています。

- 一般ファイルを新しいユーザーフォルダーへ手動コピーする方法
- Thunderbirdの保存範囲、公式インポートツールとプロファイル移行
- iPhone / iPadのMobileSyncをAppleデバイスまたはiTunesで認識・復元する方法
- 年賀状ソフトの対応製品と、各製品から住所録を開く方法
- 会計ソフトで公式バックアップを優先する注意
- Wi-Fi設定、Chrome / Edge / Firefoxブックマークの復元

Thunderbirdはメール、アカウント設定、アドレス帳、フィルター等を保存します。
保存パスワードDB、Cookie、セッションは除外するため、移行先でメールアカウントの
パスワードを再入力してください。

MobileSyncは、AppData内とユーザーフォルダー直下の両方を探索します。
復元時は元と同じ方式のMobileSync配置へ戻し、Appleデバイスアプリまたは
iTunesの「バックアップを復元」を使用します。暗号化済みバックアップには
作成時のパスワードが必要です。

■ 年賀状・会計データ

年賀状住所録は、筆王、筆ぐるめ、筆まめ、楽々はがき、宛名職人、筆休め、
はがきスタジオ、はがき作家、はがきデザインキットのフォルダーへ整理します。
移行先ソフトの公式な「開く」「取込」「復元」手順を使用してください。

会計データは弥生会計・やよいの青色申告、フリーウェイ経理の候補を
合成データで検出・分類・コピー確認しています。実会計ソフトでの読込受入は
リリース判断により省略したため、各製品の公式バックアップを必ず優先し、
Data Capsuleのコピーは補助として使用してください。

■ 署名、ハッシュ、権利

Y-TECのEXEと2つのDLLは自己署名し、第三者DLLの元の署名を保持しています。
Microsoftや商用CAの信頼済み署名ではなく、SmartScreen等の警告が出る場合があります。
公開CERは任意の検証補助物です。アプリから証明書を自動登録しません。
配布元が案内するSHA-256と、Releaseの最終ファイルハッシュ一覧を照合してください。
ZIP内の SHA256SUMS.txt では
展開後の各ファイルを確認できます。
